FAQ

Got Questions?

Here are the most common questions about GhostLink.

1Is my message really encrypted?

Yes. Your message is encrypted in your browser before it is sent, so the server does not receive it as readable text.

2Can I send images or files?

You can attach images to a message. Other file types aren’t supported yet.

3Is it really one-time only?

Yes. After the recipient opens the message, the link is permanently disabled. You can also set it to expire sooner.

4Can I add a password?

Yes. Turn on Password Lock before creating the link, then share the password with the recipient separately.

5What if I forget my password?

There’s no password reset. Ask the sender for the password; if it can’t be recovered, they’ll need to create and share a new message.
